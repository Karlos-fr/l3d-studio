## Modules sans mode autonome

- nimations/cube_greeting.cpp : séquence de texte utilisée par la démo.
- endering/primitives.cpp : primitives voxel et couleur partagées.
- endering/transitions.cpp : transitions partagées et rendu de ColorAll.
- core/legacy_state.h : état global historique conservé temporairement sans
  optimisation afin de garantir l'identité du binaire.

## Convention de migration

L3D_UNITY_BUILD n'est défini que dans main.cpp. Chaque .cpp est donc vide
lorsque Particle le compile seul, puis son implémentation est incluse une seule
fois dans l'unité principale. Cette étape intermédiaire donne des fichiers
ciblés sans changer le linkage, l'ordre d'initialisation ou la consommation
mémoire. Le passage éventuel à de vraies unités de traduction séparées devra
être mesuré dans une phase ultérieure.
